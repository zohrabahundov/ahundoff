# Ahundoff Studio — сайт

Статический сайт (HTML/CSS/JS) с PHP-обработчиком заявок `send.php`. Хостинг — Timeweb
(nginx + Apache, `.html` исполняется как PHP через `.htaccess`). RU- и EN-версии страниц
собраны из **одного общего шаблона** (`templates/`) и меняются только текста (`lang/`).

## Структура

| Файл | Назначение |
|---|---|
| `index.html`, `en.html` | Тонкие обёртки главной (задают `LANG` и подключают `templates/index.php`) |
| `privacy-policy*.html` | Тонкие обёртки политики конфиденциальности (`templates/privacy.php`) |
| `templates/` | Общая разметка страниц RU/EN (`index.php`, `privacy.php`) |
| `lang/` | Словари текстов `ru.php` / `en.php` (одинаковый набор ключей) |
| `i18n.php` | Bootstrap локализации: грузит словарь в `$t`, задаёт `$lang` и URL-хелперы |
| `partners.html`, `partners-en.html` | Тонкие обёртки партнёрской программы (RU/EN, `templates/partners.php`) |
| `vizitka-studio.html` + `vizitka.js` | Генератор визиток (препресс, QR, экспорт SVG/PNG) |
| `mail.html` | Шаблон email-рассылки (не публичная страница) |
| `404.html` | Брендированная страница ошибки |
| `send.php` | Обработчик форм (contact / partner) |
| `script.js`, `styles.css` | Общие JS и CSS |
| `partials/` | Общие header/footer/sprite/cookie-banner (PHP-инклюды, принимают `$lang`/`$t`) |
| `assets/fonts/` | Self-hosted шрифты Inter / Unbounded (variable, cyrillic+latin) |
| `assets/vendor/qrcode.min.js` | Self-hosted QR-библиотека (qrcode-generator 1.4.4) |
| `tests/` | Регрессионные тесты (см. ниже) |

## Локализация (RU/EN)

Разметка и текста разделены, чтобы локали не разъезжались:

- **Обёртка** (`index.html`, `en.html`, …) только задаёт язык и подключает шаблон:
  `define('LANG', 'en'); require __DIR__ . '/templates/index.php';`
- **Шаблон** (`templates/*.php`) содержит общую HTML-разметку и вставляет текста через
  `<?= $t['key'] ?>` (значения атрибутов — через `<?= h($t['key']) ?>`).
- **Словари** (`lang/ru.php`, `lang/en.php`) — ассоциативные массивы с одинаковым набором
  ключей. Чтобы поменять текст, правьте **оба** словаря; чтобы поменять разметку — шаблон.
- `i18n.php` грузит словарь по `LANG`, задаёт `$lang`, `$privacy_url`, `$alt_policy_url`,
  `$home_contact` и хелпер `h()`. SEO (title/description/canonical/hreflang/og/JSON-LD)
  берётся из словаря и переменных шаблона — у каждого языка свои.
- URL не меняются: `/`, `/en.html`, `/privacy-policy.html`, `/privacy-policy-en.html`.
- `templates/`, `lang/`, `i18n.php` закрыты от прямого доступа (403 в `.htaccess` и стенде).

Парность локалей проверяет офлайн-тест `php tests/i18n.test.php` (ключи совпадают, пустых
значений нет, все ключи разметки покрыты, JSON-LD валиден).

## Cookie-notice с opt-out (аудит п.8)

- Яндекс.Метрика грузится **только после согласия** на аналитические cookie. При первом визите
  показывается баннер (`partials/cookie-banner.php`): «Принять все» / «Только необходимые».
- Выбор хранится в `localStorage` (`ahundoff_cookie_consent` = `all` | `essential`).
  «Только необходимые» = аналитика не грузится, уже установленные `_ym_*` cookie удаляются.
- Изменить выбор можно в любой момент — ссылка **«Настройки cookie»** в подвале открывает баннер.
- Цели Метрики, отправленные до согласия, накапливаются и шлются после «Принять все»; при отказе — сбрасываются.
- `noscript`-пиксель Метрики удалён: без JS согласие не получить, аналитика не грузится.
- Логика — в `script.js` (модули `CookieConsent`, `Metrika`, `CookieBanner`), стили — в `styles.css`.
  inline-скриптов нет (CSP соблюдён). §7.2 политики конфиденциальности описывает механизм.

## Авто-определение языка (аудит п.16)

- При заходе на `/` сервер смотрит `Accept-Language`: если он начинается с `en` и **нет** cookie
  ручного выбора `lang_choice` — редирект 302 на `/en.html` (правило в `.htaccess`, эмуляция в `tests/router.php`).
- `script.js` фиксирует `lang_choice=<lang>` (1 год) при загрузке любой страницы — ручной выбор
  и язык последней страницы важнее авто-определения. Прямой заход на `/en.html` не редиректится.
- Ответ-редирект помечен `Vary: Accept-Language` и `Cache-Control: no-store`.
- Партнёрская программа переведена на EN (`partners-en.html`), EN-футер ведёт на неё;
  на обеих версиях есть cross-link и `hreflang` (ru/en/x-default). `hreflang` добавлен в `sitemap.xml`.
  Политики — `noindex`, поэтому `hreflang` там не применяется (только индексируемые страницы).

## Локальный запуск

```bash
# PHP-стенд (исполняет .html как PHP, письма складывает в tests/mail.out)
php -d sendmail_path="$PWD/tests/mailcatch.sh" -S 0.0.0.0:8088 -t . tests/router.php
# или: npm run serve
```

Открыть http://127.0.0.1:8088/.

## Тесты

Требуется запущенный стенд (выше) и `npm install` (для jsdom).

```bash
npm install
php tests/i18n.test.php                                   # 20 офлайн-проверок парности RU/EN
TEST_HOST=http://127.0.0.1:8088 bash tests/send.test.sh   # 35 тестов обработчика форм
TEST_HOST=http://127.0.0.1:8088 node tests/dom.test.js    # 60 DOM-тестов (jsdom): формы, cookie-banner, EN-партнёрка
TEST_HOST=http://127.0.0.1:8088 python3 tests/structure.py# структурные проверки HTML
# всё вместе: npm test
```

`send.test.sh` проверяет: методы/доступ, CSRF-защиту (Origin/Referer + кастомный заголовок),
honeypot/timestamp, валидацию полей, инъекции (CRLF/XSS), невалидный UTF-8, двухуровневый
rate limit и заголовки ответа. `dom.test.js` — формы, маску телефона, меню, FAQ, тосты,
i18n, аналитику, автоповтор при `form_expired`.

## Деплой

1. Загрузить файлы на Timeweb (корень сайта). `.htaccess` и `logs/.htaccess` обязательны.
2. **Версионирование ассетов:** при изменении `styles.css`/`script.js`/`vizitka.js` поднимать
   `?v=...` в шаблонах (`templates/`) и оставшихся HTML (`vizitka`, `mail`, `404`)
   — сейчас `2026-11-21-4`. nginx кэширует статику на год — без смены версии пользователи не
   увидят обновлений. Изображения без версии (например `founder.jpg`) при замене тоже требуют `?v=`.
3. Убедиться, что `logs/` недоступна извне (403) и права на запись есть у PHP. Требуется PHP
   с расширением `mbstring` (используется в `send.php`) и `mod_rewrite`/`mod_headers` (редирект языка).
4. HTTPS и редирект с www включаются в панели хостинга (в `.htaccess` редирект HTTPS
   закомментирован во избежание циклов).
5. После загрузки проверить: `/`, `/en.html`, `/partners.html`, `/partners-en.html`, обе политики;
   cookie-баннер появляется в новом профиле и Метрика не грузится до согласия; `/templates/`,
   `/lang/`, `/i18n.php`, `/partials/` отдают 403; заход на `/` с `Accept-Language: en` без cookie
   `lang_choice` редиректит на `/en.html`.

## Безопасность и эксплуатация (важно)

- **Ротация токенов.** GitHub PAT, передававшийся в переписке, следует отозвать и перевыпустить.
- **Персональные данные (152-ФЗ).** `logs/leads.log` хранит заявки в открытом виде. Политика
  заявляет хранение ≤12 месяцев — настройте регулярную очистку/ротацию (cron), т.к. код
  ротирует только по размеру (5 МБ). При отзыве согласия удаляйте запись вручную.
- **Почта.** SPF есть, DMARC в режиме `p=none`. После мониторинга переведите в `quarantine`/`reject`,
  проверьте DKIM. `mail()` синхронный; при сбое заявка сохраняется в лог, но владелец не
  уведомляется — рекомендуется fallback-уведомление в Telegram.
- **Rate limit и прокси.** `getClientIp()` берёт правый публичный IP из `X-Forwarded-For`
  (его дописывает nginx Timeweb). Если конфигурация прокси изменится — перепроверьте.
- **CSP.** `script-src 'self' https://mc.yandex.ru` (без `unsafe-eval`). Новые сторонние скрипты
  требуют явного добавления в CSP; inline-скрипты запрещены — выносите во внешние файлы.
- **HSTS** `includeSubDomains` — убедитесь, что все поддомены работают по HTTPS.

## Что исправлено в аудите 21.11.2026

Кратко (полный отчёт — в задаче аудита):

- **send.php:** обход rate limit через подделку X-Forwarded-For; падение в 500 на невалидном
  UTF-8; согласие по `isset` вместо значения; «сжигание» лимита ошибками валидации; тихая
  потеря лидов при устаревшей форме; слабая валидация телефона; ПДн в spam/error-логах;
  отсутствие ротации логов и лимита числа IP.
- **script.js:** потеря целей Метрики до инициализации; стирание Telegram без `@`; наложение
  тостов; зависание кнопки при обрыве сети; каскадные ошибки инициализации; работа анимаций
  вне экрана; отсутствие фокус-ловушки меню и fallback копирования.
- **HTML/CSS:** битые preload шрифтов (404) и зависимость от Google Fonts (заменено на
  self-hosted); контраст primary-кнопок (3.68→5.17); невалидный `noscript` в `head`;
  дубль `inLanguage` в JSON-LD EN; неверный URL в JSON-LD partners; разрозненные header/footer
  политик; отсутствие skip-link, safe-area, 404-страницы.
- **DRY-локализация:** RU/EN-версии главной и политики объединены в общие шаблоны
  (`templates/`) со словарями (`lang/`) — разметка одна, меняются только текста. Устранён
  рассинхрон локалей (в EN не было `yandex-verification` и вступительной фразы в §5 политики,
  порядок пунктов хранения данных отличался); CTA политики теперь ведёт на форму текущего
  языка. Добавлен офлайн-тест парности словарей.
- **Cookie-notice с opt-out (п.8):** Метрика грузится только после согласия; баннер «Принять все» /
  «Только необходимые», настройка в подвале, удаление `_ym_*` при отказе, очередь целей до согласия,
  удалён `noscript`-пиксель; §7.2 политики обновлён.
- **Полноценная EN-версия (п.16):** партнёрка переведена на EN (`partners-en.html`, общий шаблон),
  EN-футер ведёт на EN-партнёрку; авто-определение языка по `Accept-Language` с ручным переключением
  (cookie `lang_choice`); `hreflang` на индексируемых страницах и в `sitemap.xml`.
- **.htaccess:** двойной `Cache-Control`; избыточный CSP (`unsafe-eval`, jsdelivr, широкий
  `img-src`); блокировка `.well-known`; дубль `/index.html`.
- **vizitka:** страница была полностью сломана собственным CSP (inline-скрипт + cdnjs) —
  скрипт вынесен во внешний файл, QR и шрифты self-hosted.
